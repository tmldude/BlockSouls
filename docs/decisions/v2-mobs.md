# v2-mobs session decisions

Defaults picked while building Stage 6B's mobs lane (PLAN2.md §3h affixes, §3k; brief `docs/sessions/v2-mobs.md`).
Same style as `DECISIONS.md`: where this conflicts with a plan file, this logs what was actually built.

## Common affix contract (PR 1)

- **`common` stores the affix; the provider gives it meaning.** `Affixes` owns a persistent Fabric attachment
  (`blocksouls_common:affix`, one `Affix` per entity) synced to every tracking client, so the affix survives
  chunk reloads and the client can pick the tinted overlay without a custom packet. `apply` / `roll` go through a
  `Provider` the mobs module installs; the default is a no-op (`apply` → false, `roll` → empty), mirroring
  `Floors`/`Acts`. `of` reads the attachment directly, so it answers correctly even for entities affixed by
  another module's provider path (bosses) and on the client.
- **One affix per entity.** PLAN2 §3h reads "prefix + one modifier"; applying a second replaces the first. `of`
  returns `Optional<Affix>`.
- **`attach(entity, affix)` is the raw store** a provider calls; it has no behaviour, so bosses can stamp an
  affix on a field boss and still get the mobs module's modifier through `apply` when mobs is loaded.
- **`roll(random, floor)` takes the 1-based floor** (0 outside Expedition) so the provider can gate affixes by
  floor/escalation; the brief's classic-mode switch (`affixesInClassic`) lives in the provider.
- **Nameplate prefix is translatable** (`affix.blocksouls_common.<name>`), with the English prefix also on the
  enum for server-side names.
- **`roll` also takes the floor's tags** (`roll(random, floor, floorTags)`; the two-argument form passes none), so
  the provider can read the world's `elite_affixes` escalation without the mobs module looking floors up itself.

## Floor rosters (common half)

- **`WaveMobSpec` gains `minFloor` and `tags`** as new record components, with the old five-argument constructor
  kept (every floor, no tags). `tags` are floor tags the spec needs: it is eligible only on floors carrying all of
  them, which is how blight/sky mobs slot in later as data (the world adds a pool tag, the spec names it).
- **`WaveMobs.eligible(wave, floor, floorTags)`** is the floor overload; `eligible(wave)` (classic) is unchanged and
  ignores both new fields. `more_elites` lets elites skip their `minWave` on that floor (they join from the floor's
  first wave); `elite_affixes` is read by the affix roll. Both tag names are constants on `WaveMobs`.
- **Flankers are marked with an entity tag, `WaveMobs.FLANKER_TAG` (`blocksouls_flanker`).** The Director adds it
  to hunters it spawns under its `FLANKERS` composition; mobs reads it (plus its own config list of always-flanking
  mob types). A scoreboard tag needs no attachment and is saved with the entity.
- **The two new mob ids are in `CommonIds`** (`SPITTER`, `BULWARK`) so the Director's mob lists and integration's
  roster checks can name them without importing `mobs`. "Bulwark" is the shielded, must-be-flanked mob the brief
  calls "Warden-type"; vanilla already has a Warden, so it gets its own name.

## Mobs work (PR 2)

- **Affixes roll on elites from floor 2** (`mobs.json` `affixes.minFloor` 2, `chance` 0.5, `elite_affixes` floor
  tag forces a roll), Expedition only unless `affixesInClassic`. An affixed elite gets ×1.25 max health and a
  visible "Burning Brute" nameplate (`affix.blocksouls_mobs.name` = `%s %s`). The four prefix keys
  (`affix.blocksouls_common.*`) live in the mobs lang file: `common` ships no lang, and the prefix only shows when
  mobs is installed anyway.
- **Burning's trail is flames, not fire blocks.** A short-lived ground "flame" ignites non-wave-mobs that step on
  it; it never places blocks, so arenas and floor builds can't burn down. Burning hits ignite for `igniteSeconds`.
- **Frosted** slows on hit and takes `projectileDamageFactor` (0.6) from projectile damage (`#is_projectile` plus
  a config list of extra damage-type ids), via a damage mixin hook rather than an armour attribute, so melee is
  unaffected.
- **Volatile** lights a `fuseTicks` (20) fuse on death with a ring telegraph drawn at the blast's exact radius,
  then a `Shockwave` (entity damage only, no block damage).
- **Magnetic pulls items and bends player projectiles, nothing else.** Guns are hitscan, so there is nothing to
  deflect there; it pushes each player-owned `Projectile` sideways (across its flight path, never faster or
  slower), and pulls dropped items in. It doesn't pull players: forced movement fights the movement mod.
- **Overlay = one tileable pattern per affix** (`textures/entity/affix/<name>.png`, generated by
  `tools/assets/mobs.py`), drawn as a translucent-emissive layer over the base model. A pattern works on any UV
  layout, so every mob (and the Infected Piglin, via its own render state) gets it with one layer class.
- **`/bs mob affix <targets|look> <burning|frosted|volatile|magnetic|clear>`** and
  **`/bs mob roster <floor> [tags…]`** (lists what `WaveMobs.eligible` lets in at wave 50 on that floor).
- **Act rosters by `minFloor`:** floor 1 shambler, crawler, screamer; floor 2 adds spitter, bloater, brute; floor
  3 adds bulwark, mutant brute; floors 4–6 have the full roster (pool tags will narrow later floors once world
  adds them). All in `mobs.json` `roster`.
- **Hand-off: the game's `WaveManager` still uses classic `eligible(wave)`.** Switching it to the floor overload
  is in `game/run/**`, outside this lane, so rosters take effect once the game calls it (one line in
  `WaveManager`'s mob pick). Flagged in the PR for the game owner; `/bs mob roster` shows the result meanwhile.
- **Lane exception: one hook in `game/run/director/Director.java`.** After `spawnHunter`, an elite rolls an
  affix for its floor (floor number from `Floors.at`, falling back to the act ordinal, 0 = Classic), and hunters
  spawned under the `FLANKERS` composition get `WaveMobs.FLANKER_TAG`. No other Director logic changed.
- **Crawlers always flank** (`flanking.alwaysFlank`); everything else only when tagged. `FlankGoal` orbits the
  target in 40° steps at `orbitRadius` 5 until it's inside the `behindDegrees` (110°) rear arc of the party's
  mean facing, gives up after `giveUpTicks` 160, then goes straight in for as long before retrying.
- **AttackPicker** scores Brute, Mutant Brute and Screamer specials by range fit, facing, a just-rolled or
  airborne target, and a repeat penalty. The repeat penalty is skipped for a mob with a single special: it's
  about variety, and a one-attack mob would otherwise stall every other use.
- **Spitter** (floor 2): keeps range, lobs a poison glob. **Bulwark** (floor 3): front-arc shield takes
  `frontDamageFactor` of damage unless the source bypasses shields; a telegraphed shield bash. Both are wave mobs
  in `#blocksouls:wave_mobs`, burn in daylight like the other undead, and drop rotten flesh plus slime balls /
  iron nuggets (vanilla items, so no new recipe-web entries).
- **No per-party numbers in this PR.** Affix chance and modifiers are per elite; how many elites spawn is still
  the game's and Director's `PartyScaling`, so no new curve was added.
