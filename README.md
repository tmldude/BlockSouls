# BlockSouls

A Fabric modpack for Minecraft 26.3: Souls-style boss fights, Destiny-style guns, COD-style zombies waves,
web-swinging and wall-climbing, and Mario-style jumps.

- Build: `./gradlew build` (needs JDK 25)
- Plan: [PLAN.md](PLAN.md) · Decisions: [DECISIONS.md](DECISIONS.md) · Contributor notes: [CLAUDE.md](CLAUDE.md)

## Playing (friends)

1. Install the [Modrinth App](https://modrinth.com/app) and sign in with your Minecraft account.
2. Open the BlockSouls modpack link the server owner sent you (the project is unlisted) and click **Install**.
3. Play → Multiplayer → Add Server → the IP the owner gave you.

When the pack updates, the Modrinth App shows an update button on the instance. If you join with an old version,
the game tells you in chat.
